Getting started

Introduction

Softifex is a web-based ERP for pharmaceutical distribution. It keeps your products, batches and expiry dates, your purchases and sales, your accounts and ledgers, and the orders your field staff take on their phones, in one place.

This guide follows the order in which you will actually use the software: install it, do the one-time setup, then work through the daily flow of data. Every page of the software is covered, with the fields to fill in and the messages you may see.

What is in the box

PartWhat it isWho uses it
Web applicationThe main software, opened in a browser. Sidebar groups: Accounts, Products, Customers & Field, Purchase, Sales, Transactions, Stock, Reports, Users and Settings.Office staff, accounts, management
Mobile app (Android)Order-taking app for salesmen. Takes orders, cash and returns in the field, then uploads them to the web application.Salesmen and bookers

How to read this guide

  • Use the sidebar on the left to jump to a topic, or type in the search box to filter it.
  • Every page section starts with where to find it: the sidebar group and page name, and the address that page opens at.
  • Fields marked Required must be filled before the page will save.
  • If you are setting up a new company, read the sections in order. The order matters: for example, a customer cannot be created before its account exists.
Tip

You do not need to read everything. If the software is already installed and set up, go straight to How data flows and then to the page you need.

Installation

Softifex is installed on one Windows computer or server with an installer called SoftifexSetup.exe. Everyone else opens the software in a browser, and salesmen use the mobile app. Nothing is installed on the other computers.

Before you start

Check the System requirements first.

  • A Windows computer or server that stays switched on during working hours, and an administrator account on it.
  • Free disk space for the program and database, and a free network port (the setup suggests 8080 and checks that it is free).
  • You do not need to install anything else first. The installer adds the web server (IIS with ASP.NET) and the database server (SQL Server Express, installed as its own instance named SOFTIFEX) when they are missing. Other database instances on the computer are not touched.

Install steps

  1. Right-click SoftifexSetup.exe and choose Run as administrator.
  2. Read the welcome page and accept the terms to continue.
  3. If Softifex or its data is already on this computer, the setup asks what to do. On a new computer this page does not appear. See Updating and reinstalling.
  4. If the setup asks What do you want to install?, keep the default choice, the full app.
  5. Your data page: leave the saved-data file empty to start with a fresh company, or choose a .sbk file if you are moving an existing company to this computer.
  6. Website Port page: keep 8080 or type another free port. If the port is used by another program the setup tells you to choose a different one.
  7. Click Install and wait. The first install can take 15 to 30 minutes because the database server is installed as well. You can leave the window open and do other work.
  8. On the last page the setup shows the address to open, for example http://localhost:8080. Click Finish.

Where things are installed

Opening Softifex from other computers and phones

  1. On the server, find its network address (for example 192.168.1.10).
  2. On another computer in the same office, open a browser and type http://192.168.1.10:8080 (use your own address and port).
  3. To reach the server from outside the office, forward the port on your router to the server. The setup cannot do this for you. The installer opens the port in the Windows firewall on the server itself.
Note

The mobile app connects to the same address. Keep the address of the server handy: you will type it once on each phone. See Mobile app: first-time setup.

Updating and reinstalling

Run the newer SoftifexSetup.exe on the same computer. When Softifex is already installed the setup offers two choices:

ChoiceWhat happens to your data
Update to the new versionAll data is kept. The setup first saves your data and program, then installs the new version and applies any database changes. If anything fails, everything is put back as it was.
Reinstall with fresh dataAll current data is erased. You must type ERASE to continue. Use it only to start over.

If an earlier uninstall kept the database, the setup says We found your data and offers to install and use that data (it is brought up to the new version), or to install fresh data (the found data is erased).

Tip

Before any update, open Backup & Restore and press Create Backup Now. The setup also keeps its own copy in the updates folder under the install folder.

Uninstalling

Use Uninstall Softifex from Windows Settings. The website, application pool and firewall rule are always removed. You then choose what to do with your data:

OptionResult
Keep my data (default)The database, saved backups and logs stay on the computer.
Also remove the databaseType ERASE. The database and saved backups are deleted.
Remove everythingType ERASE. Also removes the SOFTIFEX database server and the install folder. IIS and SQL Server Management Studio are never removed.

System requirements

Softifex runs on one Windows computer or server (the server). Other people use it from a browser, and salesmen use the Android app. These are the minimum and recommended specifications for the server.

MinimumRecommended
WindowsWindows 10 (64-bit) or Windows Server 2016Windows 11 Pro, or Windows Server 2019 / 2022
Processor2 cores4 cores or more
Memory (RAM)8 GB16 GB or more
Free disk space30 GB100 GB or more, on an SSD
NetworkA local network (LAN) for the office computersA fixed IP address for the server. For phones outside the office: a public address or a router with port forwarding

Software the installer adds for you

You do not install these yourself. The setup adds any that are missing.

  • IIS web server with ASP.NET (.NET Framework 4.7.2).
  • SQL Server Express, installed as its own instance named SOFTIFEX.
  • SQL Server Management Studio, a free Microsoft tool for the database (optional, installed only if missing).
Note

SQL Server Express is free but has Microsoft limits: it uses up to about 1.4 GB of memory for the database, up to 4 cores, and a database size of up to 10 GB. This is enough for a typical distributor. A company with very large history should ask us about a larger database edition before installing.

Computers that only open Softifex

  • Any modern browser: Google Chrome, Microsoft Edge or Firefox, kept up to date. Chrome or Edge are recommended.
  • A screen of at least 1366 x 768. The software also adapts to tablets and smaller screens.
  • A PDF reader, to open exported reports.

Phones for the mobile app

  • An Android phone, Android 7 or newer recommended, with about 150 MB of free storage.
  • A mobile data or Wi-Fi connection to download customers and products and to upload orders. Orders can be taken without a connection and uploaded later.
  • Optional: a fingerprint or face unlock set up on the phone, for fast sign-in.
Tip

Plan for growth: 8 GB is enough to run Softifex for a small team, but if more than about 10 people work at the same time, or you run many large reports, choose 16 GB and an SSD. Keep the server on a UPS so a power cut cannot damage the database, and schedule backups (see Backup & Restore).

Opening Balances (migration)

Sidebar → Settings → Opening Balances/migration

Migration brings in the balances from your old system once, when you start: the balance of each account, what each customer owes, and the opening stock of each batch. After that you work normally with vouchers.

Important

You must contact the developer to enable migration. It is switched off by default and the Opening Balances page is not in the menu. Ask Techstersol (support@techstersol.com or WhatsApp +92 306 6940981) and we will open a migration window for your company. Only the company administrator can then see and use it.

Before you start

  • Finish the setup checklist first: accounts, customers, products and batches must already exist. Migration only adds balances to things that exist.
  • Collect the closing figures from your old system: account balances (debit and credit), what each customer owes, and the quantity on hand of each batch.
  • Do it before you start entering daily vouchers, so that the figures are not mixed.

Step 1: Download the templates

Fill in the amounts and leave the other columns as they are. Rows left empty are skipped. Debit and credit amounts can be positive or negative. Choose what you need; you can use one, two or all three.

TemplateHoldsColumns
Data LedgerThe opening balance of each account.AccountId, AccountTitle, AccountType, Dr, Cr. Use Add accounts to choose the rows. Customer account types are left out by default, because customer balances belong in the Sales Ledger; switch the option on to choose which types to leave out.
Sales LedgerHow much each customer owes.CustomerId, CustomerName, Dr, Cr, VendorGroupId (leave empty when there is none). Use Add customers.
Stock LedgerThe opening quantity of each batch.BatchStockId, BatchNo, Product, QtyIn, QtyOut. Use Add batches. The quantity is added to the stock the batch already has.

Press Download template on each one. The template is an Excel or CSV file already filled with the accounts, customers or batches you chose.

Step 2: Upload and check

  1. Drop each filled file in its box (or click to choose it). Files are .xlsx or .csv.
  2. Click Upload and check. Nothing is written to your books by uploading, and the files are kept safely until you proceed, so you can take your time.
  3. If the file has problems you see them listed by line, for example a missing column (Use the downloaded template) or a file with no rows. Fix the file and upload it again.
  • A file that was already migrated is refused, so the same balances cannot go in twice.
  • Warnings do not stop you but deserve a look: a customer account in the Data Ledger file, a batch that will show negative stock, or debit and credit totals that differ.

Step 3: Review and proceed

  1. Click Open the check report. For each account, customer and batch it shows what it holds now and what it will hold after.
  2. When you are happy, click Proceed.
  3. Type your administrator password to confirm, then click Confirm and migrate.
  4. A progress bar shows the work. It runs in the background, other screens are paused until it finishes, and you should keep the page open.
Good to know

If the report is more than 2 hours old it is made again with today’s balances when you press Proceed, and you are asked to confirm once more. A wrong password counts toward a short lock (5 tries in 15 minutes).

Important

The opening rows are dated today. A copy of the database is taken first, but the migration cannot be taken back from the software. Check the report carefully before you confirm.

After it finishes

  • The page says Opening balances are closed and shows the date it was migrated, with a link to the final report.
  • The window is closed. To migrate again, the developer must enable it again.
  • Entries appear in the Data Ledger, Sales Ledger and Stock Ledger with the remark Opening Balance of account by Migration.

The rules behind the chain

Sidebar → Settings → Backup & Restore/settings/backup

A backup is a complete protected copy of the database (saved as a .sbk file), including users, roles, settings and tax invoice. Use it to protect your data and to move to a new computer.

Create a backup

  1. Click Create Backup Now.
  2. A progress bar shows it working in the background. You can keep using the software.
  3. The file appears under Saved backups, where you can download it or delete it.

Automatic backups

Switch on Make backups automatically, choose How often and how long to Keep them. A backup named Scheduled is made in the background the first time the software is used once a backup is due. Administrators and roles that can open this page are notified when one is done.

Restore

  1. If the file was made elsewhere, Upload it first (drop the .sbk file, then it is checked).
  2. Under When restoring, keep the current, switch on anything that must stay as it is now: Users and roles, Settings, Tax invoice. Leave all off to replace everything.
  3. Click the restore button on the file in the list.
Important

Restoring replaces all current data with the data in the file and signs everyone out. Only an administrator can restore. A safety copy of the current data is saved automatically just before, so a restore can itself be undone. A file made on another installation brings that installation’s data and users.

Mobile app: overview

The Softifex mobile app is for salesmen and bookers in the field. It takes orders, cash and returns on an Android phone, keeps them on the phone, and uploads them to the web application, where the office confirms them.

The journey of one order

  1. The salesman takes the order in the app. It is saved on the phone and works without a signal.
  2. When there is a connection, the salesman uploads it. It arrives in Transactions as Pending.
  3. The office checks it and presses Confirm. An invoice is created and stock is reduced.
  4. The customer’s balance updates, and the salesman sees it on the next refresh.
Good to know

Before a salesman can use the app, an administrator must create a user for them and link it to their salesman record, and the salesman must have at least one town with customers.

Mobile app: first-time setup

Install

  1. Copy the Softifex app file (.apk) to the phone, or download it from the link given to you.
  2. Open it. If Android asks, allow installing apps from this source.
  3. Open Softifex from the app list.

Connect the app to your server

The first time the app opens it shows Setup App. This is done once per phone.

  1. Choose how you will type the address: the URL tab for a web address (for example api.mycompany.com), or the IP address tab (for example 192.168.1.2).
  2. Type the address. If your server uses a port that is not the normal one, type it in Port (optional).
  3. Tap Save.
  4. The app contacts the server. On success you see Successfully connected with “Your Company” and the sign-in page opens. If it fails you see Connection failed: check the address, the port and the phone’s connection.
Important

Ask your administrator for the address for the mobile app. It can be different from the address you type in a browser: when Softifex is installed on your own server, the setup asks for the website port and a separate port for the mobile service, and the phone must use the second one. On a local network use the server’s IP address; from outside the office the router must forward that port to the server.

Sign in

  1. Type your Username and Password (the same ones the administrator created for you on the Users page).
  2. Tap the sign-in button. You arrive on Home.

The app asks Sign in faster? after your first password sign-in. Tap Enable to use your fingerprint or face next time; you can turn it off in Profile. If the app is locked, Softifex is locked appears: use your fingerprint or face, or Use password instead.

  • A password sign-in is required at least every 30 days, even if you use fingerprint or face.
  • When you log out, unfinished drafts of the previous user are cleared so the next person does not see them.
  • If you see Enter username and password, one of the fields is empty.

Mobile app: data and uploading

Getting your customers and products

The first time you open the app each day, it shows Syncing Data with three steps: Fetch Customers, Fetch Products and Fetch Vendor Groups. You only get the customers of your own towns. Stock and prices come with the products. After you upload, the app refreshes them again, because stock and balances have changed. A company with no vendor groups is fine.

Working without a signal

Everything you enter is saved on the phone first (the app says saved (local)). You can take orders all day in an area with no network, and upload later.

Uploading

There are two ways, both on the Home tab.

WayHow
Upload everythingTap the sync icon at the top. Confirm Do you want to sync all pending transactions to the server? with Sync. A message tells you how many were uploaded.

  • Press and hold a card, then use Edit (one card at a time) or Delete (confirm with Delete in Delete Items) for work that has not been uploaded.
  • Select cards and tap the download icon to export them to a file.
  • If a phone cannot upload, export the file and the office imports it with Transaction Import.
